# Neo — Short English Brief

Neo is a TokenAI System One decision model. It reads application state and a
declared decision schema, then returns typed probabilities for `choice`,
`score`, and `noul` questions in one forward pass. Neo does not generate a
conversation or free-form explanation; it provides a calibrated signal that
software can use for routing, tool selection, safety gates, escalation, and
human review.

Canonical model reference: https://huggingface.co/tokenaii/neo
